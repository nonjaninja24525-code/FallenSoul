# FallenSoul
A single-player story: a mix of an RPG and a fighting game.

Задачи на реализацию:

1) Создать базовую тест-комнату большого размера.
2) Создать управляемого персонажа который может в ней передвигаться (WASD или стрелочки) (Передвижение по диагонали не должно быть возможным).
3) Создать объект (тестовый/плейсхолдер) с которым можно взаимодействовать (Клавиша взаимодействия по умолчанию: E или F).
4) Создать оверлей (тестовый/плейсхолдер) с текстовым диалогом.
5) Создать наборы меню (с настраиваемыми наборами опций) с текущими опциями:
   5.1) Главное меню:
         * Играть
         * Настройки
         * Выход
   5.2) Меню паузы:
         * Назад
         * Настройки
         * Главное меню
   5.3) Меню настроек:
         * Разрешение экрана(дропдаун меню)
         * Режим окна(дропдаун меню)
         * Слайдер Общей громкости
         * Слайдер Громкости музыки
         * Слайдер Громкости звуковых эффектов
         * Секция привязки клавиш, в которой можно сменить привязки управления (Формат: "[Название функции]: [Клавиша]")
